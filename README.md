## rswap

Jump to applications with as few keys as possible.

## Example

`rswap.conf`, placed next to the executable or in the working directory:

```
b = Brave
d = Discord
```

Pressing RightAlt+b will open the Brave window if one exists, otherwise it will start the Brave app.
If there are multiple Brave windows, repeated presses will cycle between them.
